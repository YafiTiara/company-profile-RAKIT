## 2. Instalasi, Build & Menjalankan Secara Lokal

```bash
# 1. Instal dependensi
npm install

# 2. Buat bundel produksi (Asset/dist/app.js & Asset/dist/app.css)
npm run build

# 3. Verifikasi integritas seluruh aset, foto, sertifikat, dan JSON
npm run check

# 4. Jalankan server pratinjau lokal (http://127.0.0.1:4174)
npm run dev
```
